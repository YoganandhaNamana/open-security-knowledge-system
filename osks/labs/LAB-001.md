# LAB-001: TCP Packet Capture & Handshake Analysis

| Property | Value |
| :--- | :--- |
| **Lab ID** | LAB-001 |
| **Domain** | Network Security |
| **Difficulty** | Intermediate |
| **Estimated Time** | 45 Minutes |

## Objectives
1. Capture raw TCP handshake flags using `tcpdump`.
2. Reconstruct sequence numbers and packet flows in Wireshark.

## Commands
```bash
sudo tcpdump -i eth0 -c 50 -w handshake_capture.pcap tcp
```

Open the capture in Wireshark and filter on `tcp.flags.syn == 1` to isolate handshake segments.
