# Contributing

Thank you for helping improve OSKS.

## Workflow

1. Review the project documentation in [osks/README.md](osks/README.md).
2. Follow the local setup steps in [README.md](README.md).
3. Run the test suite before submitting changes.
4. Keep changes focused on documentation, release hygiene, or the existing architecture.

## Pull Requests

- Describe the motivation and impact of your change.
- Include validation steps such as test results or documentation build output.
- Avoid introducing architectural rewrites or unrelated refactors.
